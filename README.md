# AndroidConsumerApp

> An Android consumer-facing application integrating a custom map library and RangeBar UI component for location-based and range-selection features.
> Language: Java | Modules: maplibrary, rangebar

---

## About

This application demonstrates integration of custom Android library modules — specifically a map library for location display and a RangeBar component for range-based UI interactions. It showcases multi-module Android project structure and custom view integration.

---

## Modules

| Module | Description |
|--------|-------------|
| `app` | Main application — activities, fragments, UI logic |
| `maplibrary` | Custom map integration module — location display, markers, overlays |
| `rangebar` | Custom RangeBar UI component — dual-handle range slider |

---

## Tech stack

| Component | Technology |
|-----------|-----------|
| Language | Java |
| UI | Custom Views, RecyclerView |
| Maps | Custom map library module |
| Range selection | RangeBar custom component |
| Build | Gradle multi-module |

---

## Key concepts

- Multi-module Android project structure
- Custom View implementation (RangeBar)
- Library module consumption from app module
- Location-based UI patterns
